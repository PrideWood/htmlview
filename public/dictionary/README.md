# 内置英汉词典

数据来源：https://github.com/skywind3000/ECDICT ，遵循 MIT 许可证，见同目录 LICENSE-ECDICT.txt。

本项目从 ecdict.csv 筛选 74,148 个词条（其中 15,191 个为短语）：全部带考试标签的词、BNC 或当代语料库词频前 50,000 的词，以及内置资料中的单词。另收录以常见动词、介词和冠词起头的二至五词短语。保留有中文释义的英文单词及带连字符、撇号的词，附加 31,748 个词形索引。中文释义、音标、英文释义、词形、考试标签均取自原词库，未使用模型生成。

词库按首字母分为 26 个 JSON 包，首次查询时从应用自身加载，浏览器内存最多保留 8 包。无需外网、API 密钥或额外运行依赖；应用本身仍需正常启动或可访问。未下载的包在浏览器完全断网时不能查询。未收录的词可点击“有道在线查词”，在新标签打开国内词典，在线服务可用性取决于用户网络。

查询大小写不敏感，支持弯撇号归一化。词形索引取自原数据 exchange 字段；有独立词条时优先展示，再补充原形释义，不通过盲目截去词尾猜测原形。词典为通用释义，需结合原文判断含义。词库可能存在原始数据错误或遗漏。

复现：从上游下载 ecdict.csv，在项目根目录执行 `python3 scripts/build-dictionary.py /path/to/ecdict.csv`。构建只使用 Python 标准库；生成文件随项目提交，启动和部署无需重新下载。manifest.json 记录原文件 SHA-256、筛选规则和字段顺序。

长按英文后可在词典窗口向前或向后扩选相邻单词，最多五个词；扩选不会跨越标点或文本节点。也可在输入框直接输入短语。未收录词组可使用有道在线查词。
