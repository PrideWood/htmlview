# 讲练 · 拍照备课 MVP

在保留原有英语题库基础上，加入“手机采集 → 视觉模型整理 → 老师校对 → 保存 → 白板演示”。需求详见 [需求与MVP范围.md](需求与MVP范围.md)。

## 本机启动

需要 Node.js 22 或更新版本。

```sh
cd 英语拍照讲练_MVP
npm ci
npm start
```

也可以在 Finder 中双击本目录的 `启动讲练.command`。

先安装已锁定依赖，再打开：

**http://127.0.0.1:8787**

电脑的 localhost 入口视为可信本机，可直接进入工作台及修改模型配置；局域网其他设备和公网入口均需手机授权。首次在可信电脑运行 `npm run phone:pair`，用自己的手机扫描并确认绑定；之后其他电脑/白板显示登录二维码，由这部手机核对六位授权码后允许登录。手机绑定180天，电脑会话12小时；只保留一部绑定手机，更换绑定会撤销全部电脑会话。详细操作见 [手机扫码登录.md](手机扫码登录.md)。

- 模型设置仅可在电脑的 localhost 入口修改；手机不需要填写密钥。
- 在“模型设置”填入国内服务商给出的 **HTTPS API基础地址**、**视觉模型ID**、**API Key**，选择“OpenAI兼容Chat”。地址通常以 `/v1` 结尾，不要重复加 `/chat/completions`。
- 模型必须同时支持图片输入和文本输出；纯OCR模型可能只会转写而不擅长生成教学解析。建议选择具备文本推理的通用视觉模型。
- JSON Mode默认关闭，以兼容更多服务商；服务商明确支持时再启用。
- “保存配置”仅保存设置，不代表已验证连通性；上传后首次识别会真实调用模型并产生服务商费用。
- 可以先点“先体验编辑与演示”，完整体验校对保存和白板演示，不调用模型、不伪装OCR。

首次运行自动建立 `data/config.json`，保存本机模型配置。模型Key只写在此服务端文件中（权限600）。绑定手机、授权请求和电脑会话在 `data/auth.json` 中保存哈希凭证。不要上传此文件；`.gitignore`已忽略 `data/` 和 `.env`。

局域网HTTP仅适合可信的同一Wi-Fi；公网使用Vercel提供的HTTPS。学校Wi-Fi若隔离终端，需要换一个可互访的网络或后续公网部署。

默认监听 `0.0.0.0:8787`，仅供本机使用可设置 `HOST=127.0.0.1`。可用 `PORT` 修改端口。环境变量覆盖网页中的本机配置，示例见 `.env.example`。

## 手机与图片顺序

手机端底部提供两个入口：左侧“拍照上传”，右侧“资料演示”。上传页保留大号拍照、相册和文档入口，以及预览、调整顺序和上传进度。

“资料演示”按“专题 → 资料 → 题目”逐层浏览，支持按资料名称/专题搜索，以及内置、我的资料、待校对、课堂资料筛选。题目页可展开阅读材料、原始图片及答案解析，切换上一题/下一题，也可打开完整课堂演示。

手机可直接编辑题干、选项、答案、解析、共享篇章和校对状态。底部固定显示“保存草稿”和“保存为课堂资料”，原生选题框可快速跳题；切题保留内存中的修改，离开页面会提醒保存。内置题库仅在点击编辑时复制为个人草稿；保存复用电脑端校验及版本冲突保护，同一站点的电脑可读取保存后的修改。手机外观沿用工作台主题，底栏适配安全区域。

每份支持最多10张图片，分小请求逐张保存。遇到上传中断，已成功保存的图片保留，保持选择再次点击可继续。照片中的题号、页码和阅读材料续接关系用于推断顺序；电脑编辑页展示建议页序和每题来源图片。无法确定顺序时保留上传顺序并提示核对。

## 文档上传

支持 DOC、DOCX、Markdown（MD）、TXT，每份一份文档，可附带照片和补充文字。文件不超过2MB，提取文字与补充文字合计不超过10万字。DOC 和 DOCX 均可直接上传；Word提取段落及表格文字，内嵌扫描图片需另外通过照片入口上传。文档原件保存于私有存储，可在编辑页下载；模型整理后仍须逐题校对。旧版 DOC 由纯 Node.js 解析器处理，不依赖安装 Office；加密、损坏或扫描型文档会提示另存或上传照片。

长文本按题目边界自动分批（目标每批8题或约3500字），整理时提供完整原文以补齐跨批阅读材料。若模型输出截断或 JSON 不完整，自动缩小当前批次后继续。每个批次独立请求并保存进度，界面显示已完成/剩余批次；中断后打开该资料，点击“继续整理”或“开始 / 重试识别”即可续接。整理完成后按原文顺序合并，重复的原题号自动增加后缀。单份资料最多1000题；修改原文并保存会重置批次进度。多图仍优先整体识别页序，输出截断时再按图片分组；单页或单题反复截断会保留进度并提示更换模型。

## 题型支持

模型整理与校对表单可区分：单项选择、多项选择、阅读理解、完形填空、七选五/其他选句填空、信息匹配/选词填空、语法/词形填空、改错、翻译、阅读简答、书面表达和讲解卡。未知题型保留原文并标为待确认。

- 七选五、完形及匹配按每个空或匹配项独立保存，保留完整文章、原题要求与共享选项。七选五每空均保留 A—G（含多余选项），缺项会标为待确认；选项库最多支持 A—Z。选项能否重复使用以原题要求为准。
- 校对页题号按顺序自动换行排列，无需横向滚动；默认按数值原题号排序，保留章节重号的分组。可点击“按原题号排序”恢复编号顺序；使用前移/后移后会保存为手动顺序。可选择“具体题型”，编辑“原始空号/小题号”和“同篇材料编号”。章节前缀或批次合并改变题号时，原始空号仍用于文章高亮。同一篇材料切换小题保留滚动位置；完形填空当前空号超出文章可视区域时自动滚动到空号，不同材料组重新定位。
- 多选题选择全部答案后点击“确认选择”；全部选对且不多选、不漏选才算正确。可用 Tab 轮选选项和确认按钮，Enter 操作当前选中项。只显示参考答案不计分。
- 填空、改错、翻译和简答展示参考答案，写作保留题目要求与参考范文；这些题继续使用原有逐项揭示和解析功能。
- 自动分批时使用完整参考原文补齐跨批材料和共享选项。篇章在 materials 中完整保存一次，通过 groupId 关联小题，避免每题重复输出全文造成截断；保存不再截掉材料超过50段或单段超过2万字的内容。演示左侧独立滚动完整篇章，右侧显示当前小题及选项；段落、标题、题型说明、表格文字与空格都应保留，整理后仍需逐题校对。
- 对已经缺失篇章的旧资料，在校对页点击“补全篇章”：从已保存原文/照片分批重新提取材料，保留原有小题、答案和解析，受影响小题需重新核对。补全中断后可继续。旧资料尚未关联篇章时，演示会显示已保存原始全文或原图并提示补全，不隐藏资料。
- 草稿允许只完成部分校对；空题干、缺少选项、无效答案作为待确认题保存且不计分，不阻止其他已校对内容保存。无选项且需文字作答的填空/句型转换会纠正误标的选择题展示方式；明确选择的问答方式不会再被旧题型标签覆盖。校验提示同时注明原题号和列表位置。

## 长按查词

课堂演示中，长按文章、题干、选项或解析中的英文约半秒，即可打开随演示主题变化的词典窗口。拖动或滑动会取消长按；长按选项不会提交答案，解析内查词不会关闭原解析。长按后的词典窗口支持“向前扩选 / 向后扩选”，可组合最多五个相邻英文单词查询短语。也可点击左上角词典图标输入单词，按 Enter 查询，按 Esc 或点击关闭按钮返回阅读。词典打开时翻页笔不会切换题目。

随项目内置 ECDICT 英汉词典包（约 7.4 万词条、3.2 万词形索引，约 13 MB），包含中文释义、音标、英文释义、词形变化与考试标签，按首字母按需加载。查询不依赖外网、模型或 API 密钥；本机服务仍须运行，云端使用须能访问应用。未加载的词典包在浏览器完全断网时无法读取。未收录词提供“有道在线查词”新标签入口，需联网。来源、MIT 许可和重建方法见 [词库说明](public/dictionary/README.md)。

## 删除与回收站

资料库的文件行及详情面板提供“删除”，校对页也可删除当前资料。确认弹窗确认后，资料移入“回收站”，普通列表不再显示；可在回收站选择“恢复”，资料状态和原始附件随之恢复。“已收起”与回收站分别管理。内置题库移入回收站时只保存可恢复的隐藏状态，原始题库保持完整。回收站不自动清空。

## 保存与备份

- `seed/lessons.json`：145份内置题库，共2570项（原51份1570项 + 2025单招题库94份1000题）；只读，不在网页直接覆盖。新增1000题均含逐题补编解析，244道阅读题已依据篇章补答；20道原题歧义题暂不计分。答案核对和复现方法见 [导入说明](review/单招1000题导入说明.md)。
- `data/lessons/`：你的新资料、草稿和收起资料；按资料原子写入JSON，带版本冲突检查。
- `data/images/`：上传文档原件和压缩后实际发送给模型的照片。浏览器会把手机原照片转换为JPEG，所以不是手机相机原始文件的无损备份。
- `data/config.json`：本机配置；不要分享或提交Git。
- JSON导出只包含题目和解析，不包含照片或文档附件。完整本机备份请在停止服务后复制整个 `data/`，妥善保管其中配置。
- 页面刷新不会丢已保存资料；尚未保存的编辑会在离开前提示。编辑不是自动保存，请点击保存草稿。

## 部署配置

已提供 `vercel.json`、`api/index.mjs`、Neon与私有Blob适配。此次不执行公网发布。

1. 将本MVP目录作为独立仓库或Vercel项目Root Directory；不要把相邻的旧版HTML目录或本机data上传。
2. 执行 `npm ci`，确保使用已锁定依赖。
3. 在 Vercel 连接 Neon PostgreSQL 和**私有** Vercel Blob，并设置环境变量：

| 变量 | 作用 |
| --- | --- |
| `DATABASE_URL` | Neon提供的PostgreSQL连接串；首次请求会创建classroom_lessons表，需要建表权限 |
| `BLOB_READ_WRITE_TOKEN` | 私有Blob存储令牌 |
| `MODEL_BASE_URL` | 国内视觉模型的兼容API基础地址 |
| `MODEL_API_KEY` | 服务商密钥 |
| `MODEL_ID` | 支持图片输入的模型ID |
| `MODEL_API_MODE` | `chat`（默认）或`responses` |
| `MODEL_JSON_MODE` | 仅在兼容Chat服务支持时设为`true` |
| `APP_URL` | 可选覆盖正式网站根地址；云端默认https://ppt.dacnote.com，扫码入口/phone |

4. 部署后先按 [手机扫码登录.md](手机扫码登录.md) 生成一次性二维码，绑定自己的手机，再用手机授权电脑登录。通过HTTPS链接访问。云端只从环境变量读取密钥，网页不允许修改配置。
5. 手机和白板登录同一站点，即共享数据库中的资料。本机data不会自动迁移至云端，可先导出JSON再导入；这只迁移题目，不迁移照片。全部145份内置题库已随代码包含，无需迁移。

Vercel API单次函数最大执行时间在配置中为300秒；每批模型请求在180秒超时，实际可用时长仍依套餐配置。MVP每份最多10张，每张压缩后小于1MB，浏览器逐张保存，单次请求低于Vercel的4.5MB限制。模型结合题号、页码与材料续接识别阅读顺序，保留来源图片编号与排序说明。长文本由浏览器自动发起后续批次，每次函数调用只处理一个批次，避免整份资料共用单次函数时限。关闭页面会暂停后续请求，已完成批次仍保留；更大文件后续应采用客户端直传对象存储及后台队列。

参考官方文档：
- [Vercel Functions限制](https://vercel.com/docs/functions/limitations)
- [Vercel Blob SDK](https://vercel.com/docs/vercel-blob/using-blob-sdk)
- [Neon Serverless Driver](https://neon.com/docs/serverless/serverless-driver)
- [阿里云视觉模型兼容接口](https://help.aliyun.com/en/model-studio/qwen-vl-compatible-with-openai)
- [OpenAI图片输入](https://developers.openai.com/api/docs/guides/images-vision)
