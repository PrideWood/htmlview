## 复现与检查

导入脚本：`scripts/import-danzhao-2025.py`。运行环境需要Python的pdfplumber、Poppler的pdftotext/pdftoppm，以及Node.js。传入题库PDF、答案PDF两个路径；按固定ID替换此次导入内容，其他资料保持不动。脚本检查章节、连续题号、选项及答案数量；原件SHA-256与导入统计在机器报告中。

```sh
python3 scripts/import-danzhao-2025.py "题库.pdf" "答案.pdf"
npm test
npm run check
node scripts/build.mjs
```
