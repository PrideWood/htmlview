# 八课英语精选讲义

- [教师版：八课完整讲义](教师版_八课完整讲义.md)：课程安排、完整题目、200 小题答案与解析、来源。
- [学生版：八课练习](学生版_八课练习.md)：同一套题，不附答案。
- [选题与校对记录](选题与校对记录.md)：筛选范围、剔除疑点、逐项校订和核查边界。
- `编排清单.json`：原资料 ID、原题号、答案与校订记录，便于追溯。

每课 50 分钟，10 道单选、1 篇十空完形、1 篇五题阅读。现有题库足量，未新增网络题。少量局部修复题明确标为校订版；原题库文件保持不变。

## 扩充与课堂演示

教师版含99个知识串讲模块，覆盖80道单选及16篇篇章。工作台侧边栏“课堂资料”显示第01—08课；进入演示后，扩充内容在原有“查看解析”界面中展开，题目页面保持原样。原题库从“内置题库”访问。

重建：在项目中运行 `python3 scripts/build-eight-course-handouts.py`。串讲内容源为 `seed/eight-course-teaching.json`，会同步生成教师讲义与课堂演示资料。
